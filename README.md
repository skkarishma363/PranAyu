# PranAyu
PranAyu 🌿

PranAyu is a healthcare and wellness platform designed to provide users with simple home remedies, health guidance, medicine reminders, and support from ASHA workers. The application aims to improve healthcare accessibility, especially for rural and remote communities.

🚀 Features
👤 User Authentication
Secure Signup & Login
Role-based registration
User (Patient)
ASHA Worker
Password visibility toggle
Mobile number authentication
🌿 Home Remedies
Remedy cards for common health conditions
Easy-to-understand treatment suggestions
Simple and user-friendly interface
⏰ Medicine Reminder System
Schedule medicine reminders
Notification alerts for users
Future support for notifications even when the app is closed
👩‍⚕️ ASHA Worker Support
Dedicated ASHA Worker role
Health assistance and guidance
Community healthcare support
🎨 Modern UI
Nature-inspired green theme
Responsive design
Clean and accessible user experience
Consistent branding across all pages
